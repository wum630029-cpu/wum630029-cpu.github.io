## 一、先认界面：简版与专业版

打开 App 的第一屏，不同版本、不同地区可能长得不一样。先确认自己在哪个模式：

| 维度 | 简版 | 专业版 | 所以选哪个 |
|---|---|---|---|
| **适合谁** | 第一次用、只想买币和看余额 | 要看 K 线、挂限价单、用止盈止损 | 第一次用选简版 |
| **首页** | 热门币种、买/卖/兑换、钱包余额 | 行情列表、交易对、深度图、更多功能入口 | 想少受干扰选简版 |
| **下单** | 大按钮，按金额买或卖 | 完整订单簿，可选限价、市价、止损等 | 只买币选简版 |
| **功能范围** | 只保留高频功能 | 现货、合约、杠杆、理财、C2C 等入口齐全 | 要用合约或理财再切专业版 |
| **费率** | 与专业版相同 | 与简版相同 | 费率一样，不构成选择理由 |
| **怎么切换** | 账户中心 → App 模式 → 选简版 | 账户中心 → App 模式 → 选专业版 | 随时可切，不用纠结 |

判断标准：**还在问「买完为什么不能交易」「限价单在哪」，就留在简版。** 简版收起复杂入口，反而少踩坑。**切换模式不会改变账户、资产、费率或 KYC 状态**，它只是换一套界面，不是另一个账户。

## 二、中文界面怎么设

按这个路径走：

1. 打开 App，点左上角头像或进入「账户中心」。
2. 找到「设置」。
3. 进「语言」，选「简体中文」或「繁体中文」。
4. 确认后 App 可能自动刷新；没有刷新就完全退出再打开一次。

网页端的语言是另一套设置：右上角地球图标，或页面底部的语言下拉框，也可以直接访问 binance.com 的 /zh-CN 路径。**App 和网页端的语言偏好不共享**，在 App 里设了中文，网页端仍可能是英文，需要各设一次。

设完还是英文，按下面这张表对号入座：

| 现象 | 原因 | 处理 |
|---|---|---|
| 菜单是中文，但交易对、指标名仍是英文 | 正常 | BTC/USDT、MACD、RSI 这类专业术语本来就不翻译 |
| 整个界面仍是英文 | 语言没保存成功，或系统语言覆盖 | 重新进设置确认；退出重登；更新 App |
| 找不到「语言」入口 | 版本过旧，或简版入口位置不同 | 先升级 App；在设置顶部搜索「语言」 |
| 切换后部分页面还是英文 | 缓存未刷新 | 清缓存、强制退出、重新打开 |

还有一条安全提醒：**切换中文后，主动私信你的「中文客服」基本都是骗子。** 官方客服只在 App 内的帮助中心或官网工单系统里，不会加你微信、Telegram，也不会索要验证码、密码或助记词。

## 三、两层账户：资金账户与现货账户

这是新手最该先弄懂的一张表：

| 账户 | 放什么 | 典型来源 | 能做什么 |
|---|---|---|---|
| **资金账户** | 充值、C2C 买入、提现的默认落点 | 链上充值、C2C 买币、一键买币 | 充值、提现、划转，不能直接下现货单 |
| **现货账户** | 用于现货交易的币 | 从资金账户划转、现货买入 | 下现货单、参与部分活动 |
| **其他账户** | 理财、合约等独立账户 | 从资金或现货划转 | 对应产品的申购与交易 |

所以「买完币不能交易」的答案通常只有一句话：**币在资金账户，没划到现货账户。**

划转路径：资金账户 → 划转 → 选择「资金账户 → 现货账户」→ 输入数量 → 确认。**划转免费、即时到账，不产生手续费。** 反过来，现货卖出后想把钱提走，也要先划回资金账户再提现。

判断标准：下单页看不到可用余额，先看右上角当前账户是「资金」还是「现货」；九成情况是选错了账户，不是币没了。

## 四、第一次买币：四条路怎么选

币安 App 里买币不止一个入口，价格和路径差别不小：

| 方式 | 本质 | 适合谁 | 成本与注意 |
|---|---|---|---|
| **一键买币** | 平台或第三方报价，用银行卡、支付方式直接买 | 第一次买、金额小、图省事 | 报价含价差，常见 1%–3%，随支付方式和币种波动 |
| **C2C** | 跟认证商家买，平台托管 | 金额较大、想控成本、需要法币出入金 | 平台不收手续费，成本在商家报价里，常见 0.5%–2% |
| **闪兑** | 用一种币按报价换另一种币 | 手里已经有 USDT，想换 BTC 等 | 按实时报价成交，适合小额快速换仓 |
| **现货交易** | 在交易对里挂单或吃单 | 已经会看盘、要精确控制价格 | 基础手续费 0.1%，开 BNB 抵扣与返佣后更低 |

给新手的顺序建议：

1. **第一次只买小额**，用一键买币把流程走通，确认充值、划转、下单、提现各环节都能走。
2. **金额变大后转 C2C**，对比商家报价，别只看「手续费 0」。
3. **已有 USDT 想换其他币**，用闪兑最省事。
4. **要长期交易**，再学现货的限价单和市价单。

C2C 有三条硬规则，违反任何一条都可能钱货两空：

- **只在平台订单页付款**，不按商家要求加微信、支付宝私下转。
- **付款后回到订单页点「我已付款」**，不要只截图发给商家。
- **商家要求取消订单、改价、走平台外交易的，直接拒绝并举报。**

## 五、下单：限价单与市价单

第一单建议用市价单，金额小，先弄懂流程：

1. 底部点「交易」→ 选「现货」。
2. 搜索交易对，比如 BTC/USDT。
3. 选择「买入」。
4. 订单类型选「市价」。
5. 输入金额，点「买入 BTC」。
6. 在「当前委托」或「历史委托」里确认成交状态。

两种订单的区别：

| 订单类型 | 你定什么 | 成交方式 | 适合场景 |
|---|---|---|---|
| **市价单** | 只定金额或数量 | 按当前市场价立即成交 | 想马上买到，接受滑点 |
| **限价单** | 自己定价格 | 价格到了才成交，可能一直挂着 | 不着急，想买得更便宜 |
| **止损/止盈单** | 触发价与委托价 | 触发后自动下单 | 专业版功能，新手先别急着用 |

三个容易吃亏的细节：

- **市价单不是「按你看到的价格成交」**，大额订单会吃掉多个价位，实际成交均价可能更差。
- **限价单可能一直不成交**，尤其是你把价格定得离市场很远；挂单期间币还在账户里，但没成交就是没买到。
- **不要用「全部」余额试单**，第一次留一点余量，避免手续费扣完后余额不足。

## 六、六个最常找不到的功能位置

| 你要找的 | 位置 | 备注 |
|---|---|---|
| **充值** | 首页「充值」或资金账户 → 充币 | 先选币种，再选网络；网络选错可能丢币 |
| **提现** | 资金账户 → 提现 | 需要先完成身份认证；地址和网络要同时核对 |
| **划转** | 资金账户 → 划转 | 资金账户与现货账户之间免费互转 |
| **订单记录** | 交易 → 现货 → 当前委托 / 历史委托 | 市价单成交快，容易在「当前委托」里看不到 |
| **费率与返佣** | 账户中心 → 费率 / VIP | 费率只跟 VIP 等级、BNB 抵扣、返佣有关 |
| **客服** | 账户中心 → 帮助中心 / 在线客服 | 只走 App 内入口，不信私信里的「中文客服」 |

再加两个高频位置：**2FA 在「账户中心 → 安全」；语言在「账户中心 → 设置 → 语言」。** 把这几项先走一遍，后面遇到问题就不用在菜单里乱翻了。

### 四种卡点，按状态处理

**状态一：买完币不能下单。** 币在资金账户，去「资金账户 → 划转」转到现货账户，免费且即时。

**状态二：语言设了不生效。** 退出重开、清缓存、更新 App；网页端要单独设。

**状态三：充值显示成功但余额没变。** 核对币种、网络和确认数；地址或网络选错，直接走官方工单。

**状态四：App 打不开、闪退。** 强制退出、重启、清缓存；重装前先确认验证器和恢复密钥可用。

## 七、注册后十分钟：先做这四项安全设置

| 设置项 | 位置 | 为什么现在做 |
|---|---|---|
| **两步验证（验证器优先）** | 账户中心 → 安全 | 短信验证有补卡风险；验证器更稳，恢复密钥抄在纸上 |
| **防钓鱼码** | 账户中心 → 安全 | 官方邮件会带这个码，没有码的邮件一律当假邮件 |
| **登录设备管理** | 账户中心 → 安全 → 设备管理 | 定期移除不认识的设备，发现异常登录能及时处理 |
| **提币地址白名单** | 账户中心 → 安全 → 提币白名单 | 即使密码泄露，攻击者也提不到新地址 |

另外两条使用习惯：**不要在公共 Wi-Fi 下做大额提现；不要把自己的账户借给任何人。** 出借账户不仅可能触发风控，后续纠纷也很难说清。

身份认证（KYC）也建议尽早完成。**未完成认证时，交易、提现和部分法币功能会受限**，具体以页面提示为准。被退回时先看退回原因，再重提，不要连续盲目提交。

## 八、算一笔账：第一笔买入的真实成本

以买 1,000 USDT 为例，把三条路的成本拆开：

| 路径 | 显性费用 | 隐性成本 | 1,000 USDT 的大致差额 |
|---|---|---|---|
| 一键买币 | 页面可能显示 0 手续费 | 报价价差，常见 1%–3% | 10–30 USDT |
| C2C | 平台手续费 0 | 商家报价价差，常见 0.5%–2% | 5–20 USDT |
| 现货买入 | 基础 0.1%，开 BNB 抵扣约 0.075%，叠返佣约 0.06% | 需要先有 USDT，且要会下单 | 约 0.6–1 USDT |

这张表说明两件事：**「0 手续费」不等于零成本**，成本藏在报价里；**小额图方便，大额看价差**——买 100 USDT 多花 1–3 USDT 可以接受，买 10,000 USDT 价差可能到几百 USDT，就值得走 C2C 或现货。

现货手续费的具体算法、BNB 抵扣和返佣叠加顺序，见 [币安手续费怎么算](/binance-fee-guide/)，这里不重复。

## 九、风险：这些功能，新手先别碰

- **合约与杠杆**：有强制平仓机制，方向错或保证金不足都会爆仓。没弄懂保证金率和强平价之前不要开。
- **高收益理财、双币投资**：收益率高往往对应更高的本金风险，部分产品在极端行情下会亏损本金。
- **跟单、带单、喊单群**：别人的历史收益不等于你的未来收益，跟单还可能涉及额外费用。
- **场外私下换汇、代买代卖**：对方跑路、收到问题资金导致银行卡被冻，都是常见后果。
- **任何索要验证码、密码、助记词，或要求共享屏幕的「客服」**：官方不会做这些事，直接挂断并在 App 内举报。

## 十、六个常见误区

1. **「简版是另一个账户」** → 同一个账户的两种界面，资产、费率、KYC 完全通用。
2. **「买完币就能直接交易」** → 一键买币和 C2C 默认进资金账户，要先划转到现货账户。
3. **「市价单一定比限价单划算」** → 市价单吃当前深度，可能有滑点；限价单价格可控，但可能不成交。
4. **「0 手续费就是没成本」** → 成本在报价价差里，比价要比「到手多少」。
5. **「App 里的中文客服私信是真的」** → 官方客服不会主动私信索要验证码或要求转账。
6. **「卸载重装能解决所有问题」** → 卸载可能清掉登录态和 2FA 配置，先按语言、缓存、版本、网络的顺序排查。

## 常见问题

**Q：币安 App 怎么设置中文？**

账户中心 → 设置 → 语言 → 简体中文，确认后重启 App。网页端要单独设一次，两边语言偏好不共享。

**Q：简版和专业版有什么区别？该用哪个？**

简版收起复杂入口，适合第一次用；专业版有完整 K 线、订单簿和订单类型。两者是同一账户的两种界面，资产和费率通用，随时可切。新手先用简版。

**Q：买完币为什么不能下单？**

币在资金账户，现货下单要用现货账户。去「资金账户 → 划转」，把币转到现货账户，划转免费且即时。

**Q：一键买币和 C2C 哪个划算？**

看金额。小额图省事用一键买币；金额大、想控成本走 C2C。两者都可能显示 0 手续费，真实成本在报价价差里，比较时看到手数量。

**Q：币安 App 一定要实名认证吗？**

大部分交易、提现和法币功能都要求完成身份认证，未认证会受限。具体要求以你所在地区和页面提示为准。

**Q：安卓用官网 APK 装的，App 内提示更新怎么办？**

官网 APK 不走应用商店的更新通道，提示更新时回 binance.com 下载页取新版本，直接覆盖安装，不要先卸载。卸载会清掉登录态和验证器配置，重装后可能还要重新走验证。具体步骤见[安卓 APK 教程](/binance-android-download-guide/)。

**Q：换手机后 App 怎么恢复？**

用原账号登录，重新完成设备验证；如果之前绑定了验证器，需要输入验证器码。换手机前先确认恢复密钥或备用验证方式可用，避免旧设备丢失后进不去。
