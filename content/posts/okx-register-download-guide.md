## 一、下载 OKX App：苹果、安卓、电脑三端怎么下

OKX 官方 App **不向中国大陆应用商店提供下载**，所以你在国内 App Store / 应用商店搜「OKX」「欧易」，要么搜不到，要么搜到的是碰瓷的山寨 App。正版只有下面三条官方渠道。

### 1. 苹果 iOS：切海外 Apple ID

iPhone 用户需要换一个海外 Apple ID 才能在 App Store 搜到正版：

1. **退出大陆 Apple ID**：打开 App Store → 点右上角头像 → 滑到底部「退出登录」；
2. **登录海外 Apple ID**：自己免费注册一个（国家/地区选**香港或美国**，港区支持 +86 手机号收验证码，对大陆用户最友好），或某宝买一个现成的；
3. **搜「OKX」下载**：认准开发者是 **OKX Inc.**。

⚠️ 买来的海外 ID **只在 App Store 登录，绝不登录 iCloud**——用别人的 ID 登 iCloud，对方能远程锁机敲诈。登录时若弹「是否合并数据」，选「不合并」。

### 2. 安卓：官网下 APK

安卓用户**不要从任何应用商店、第三方网站下载**，只从官网下：

1. 浏览器手动输入 **www.okx.com**（别从搜索结果点广告链接）；

3. 安装前核对：**包名 com.okex.android、签名证书 OKX PTE. LTD.**，对得上才是正版。

## 三、KYC 实名认证：用身份证就能完成

注册完只是有了「半成品账号」，**不完成 KYC 就无法充值、交易、提现**，只能看行情。所以注册后要马上做实名认证。

### 认证材料

| 项目 | 要求 |
|------|------|
| 证件 | 大陆用户**二代身份证即可**，也支持护照 |
| 年龄 | 年满 **18 周岁** |
| 证件有效期 | **≥60 天**（快过期先去换新证） |
| 拍摄 | 实体证件原件，白天自然光下拍，四角完整入框，别对屏幕翻拍 |

### 认证步骤

1. 进入「身份认证 / KYC」页面，选国家/地区、证件类型；
2. 上传证件正反面（拍照要清晰、无反光、四角全）；
3. 按提示完成**人脸识别**（光线均匀、摘眼镜、只留一人入镜）；
4. 提交后等待审核，通过即可正常使用。

下载注册只是开始，**安全设置不做好，账户等于裸奔**。注册完第一时间做这三项：
