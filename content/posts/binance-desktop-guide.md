## 一、先做选择：三种电脑端形态，别一上来就装

电脑上「用币安」并不只有装客户端一条路。三种形态的差别如下：

| 形态 | 适合谁 | 优点 | 代价 | 所以选哪个 |
|---|---|---|---|---|
| **网页版** | 一周打开几次、公共电脑、旧电脑、只想查行情 | 免安装、不占磁盘、永远是最新版本 | 关掉浏览器就没了，系统通知弱 | 一周用不到三次，或电脑不是自己的 |
| **桌面客户端** | 每天长时间盯盘、多屏、挂限价单、要托盘提醒 | 独立窗口、多屏摆放、系统通知、启动时检查更新 | 占内存、要安装和更新、公共电脑不适合 | 每天盯盘超过一小时，或同时看多个交易对 |
| **PWA（浏览器安装）** | 想要独立窗口，但不想装 exe 或 dmg | 有独立图标和窗口，本质仍是网页 | 功能受浏览器限制，通知依赖浏览器权限 | 想要独立窗口，但不想装安装包 |

判断标准只有两条：

1. **一周打开少于三次**：用网页版。装客户端的安装、更新、卸载时间，比你省下的操作还多。
2. **每天连续使用超过一小时，或同时盯多个交易对**：客户端值得装。独立窗口和多屏摆放是网页版替代不了的。

还有一条容易被忽略：**公司电脑、共用电脑、网吧电脑不要装客户端。** 它会留下登录态和本地缓存，网页版退出即走。

## 二、官方下载入口怎么认

正确的路径只有一条：

1. 在浏览器地址栏**手动输入 binance.com**，不要从聊天软件、短视频、搜索结果里的推广位跳转。
2. 进入官网后找「下载」，或直接进 binance.com 下的 /download 页面。
3. 页面会按你的地区和系统显示对应入口；Windows 安装包的实际下载域名通常是 download.binance.com。

这里有个现实情况：**同一个下载页，不同地区、不同语言版本显示的平台入口可能不一样。** 有的同时列 Windows 和 macOS，有的只列 Windows。只看到 Windows 时，先确认有没有折叠入口、换语言再看一次；仍然没有，就先用网页版。**任何第三方站的「Mac 版补丁」「Windows 加速版」都不要用。**

看到下面这些特征，直接关掉：

| 页面特征 | 为什么危险 |
|---|---|
| 域名带连字符、地区词、拼音，如 tl-binance、dn-binance、bibinance | 仿冒站常用拼写变形，页面可以做得比官网还像 |
| 下载前要求加群、关注公众号、填邀请码 | 官方下载不需要这些前置动作 |
| 安装包只有几 MB，或文件名带「加速」「绿色」「破解」「汉化」 | 正常安装包是百兆级，改版包是木马重灾区 |
| 页面提供「直链下载」「网盘下载」「历史版本合集」 | 无法验证文件是否被替换 |
| 搜索结果的「广告」「赞助」位 | 广告位可以买到，排名不等于官方 |

判断标准：**域名主体是不是 binance.com、安装包是不是从 download.binance.com 这类官方域名发出、签名能不能追溯到 Binance。** 三条都过，才继续。

## 三、Windows 安装步骤

按顺序做，每一步都有判断点：

1. **下载安装包。** 文件应为百兆级；下载完先看大小，几百 KB 的「安装包」基本是空壳。
2. **先验签名，再双击。** 右键安装包 → 属性 → 数字签名，签名者名称应能追溯到 Binance 相关主体。签名缺失、签名者是个陌生个人名，停止安装。
3. **处理 SmartScreen。** 首次运行可能提示「Windows 已保护你的电脑」或「未知发布者」。只有在来源和签名都确认无误时，才点「更多信息」→「仍要运行」。
4. **处理杀毒软件拦截。** 360、腾讯电脑管家、火绒等可能把独立安装程序误报。做法是查看拦截记录、把安装包加入信任，而不是整体关闭杀毒软件。
5. **选择安装位置。** 默认路径即可；C 盘空间紧张时再改到其他盘，别装进临时目录。
6. **首次启动并登录。** 登录后先确认右上角账户、费率等级、2FA 状态与网页版一致，再开始操作。
7. **按需设置开机自启。** 不常看盘就关掉，避免每次开机多一个后台进程。

如果第 2 步签名就不对，后面几步全部不用做。**安装包的真假在双击之前就能判断，不要等装完再查。**

## 四、macOS 安装步骤

Mac 用户多两道系统检查，步骤本身不复杂：

1. **下载 dmg。** 如果页面提供 Intel 与 Apple Silicon 两个版本，按「关于本机 → 芯片」选择；选错通常能打开，但性能和稳定性会受影响。
2. **打开 dmg，把应用拖进「应用程序」。** 不要直接在 dmg 里双击运行，那样每次都要重新挂载。
3. **首次打开被 Gatekeeper 拦下。** 提示「无法验证开发者」时，去「系统设置 → 隐私与安全性」，在下方找到被拦截的应用，点「仍要打开」。这是系统级确认，不是让你关闭 Gatekeeper。
4. **提示「已损坏，无法打开」。** 多数是下载不完整或文件被加上了隔离属性。先删掉重新从官网下载；仍然不行，再用系统终端清除该应用的隔离属性，然后重新打开。不要为此关闭系统完整性保护。
5. **验签。** 在终端对应用执行签名检查，签名主体应能追溯到 Binance。不会用终端也没关系，至少确认安装包来自 binance.com 域，且没有经过第三方转存。
6. **登录后核对账户状态。** 与 Windows 一样，先看费率、2FA、设备管理是否与网页版一致。

Mac 上最常见的误操作，是遇到拦截就去搜「关闭 Gatekeeper 的命令」。**为了装一个来源不明的包而降低整台电脑的安全级别，代价远大于省下的几分钟。**

## 五、客户端和网页版到底差在哪

两者共用同一个账户、同一套资产和同一个撮合系统，差别主要在「使用形态」，不在「交易能力」：

| 维度 | 网页版 | 桌面客户端 |
|---|---|---|
| 现货、合约下单 | 支持 | 支持 |
| 多窗口、多屏摆放 | 浏览器多标签，窗口管理弱 | 独立窗口，可自由摆放 |
| 系统托盘、桌面通知 | 弱，依赖浏览器 | 支持 |
| 自动更新 | 打开即最新 | 启动时检查更新 |
| 资源占用 | 较低 | 较高，独立进程常驻 |
| 公共电脑 | 适合，退出即走 | 不适合，会留登录态 |
| 部分活动页、C2C、Launchpad 等 | 入口完整 | 可能没有入口，需回网页或手机 App |

最后一行要特别提醒：**客户端不是网页版的超集。** 有些活动页、C2C 入口、Launchpad 或部分理财申购在客户端里找不到，需要回网页版或手机 App；这是产品入口没做进去，不是客户端坏了。

## 六、打不开、白屏、更新失败怎么排

按现象对号入座，顺序不要乱：

| 现象 | 常见原因 | 优先处理 |
|---|---|---|
| 双击没反应 | 权限不足、杀毒软件静默拦截 | 右键以管理员身份运行；查看杀毒软件拦截记录 |
| 打开后白屏 | 旧版残留、缓存损坏、显卡加速冲突 | 完全退出后重启；清理缓存；关闭硬件加速再试 |
| 一直转圈、登录不上 | 网络拦截、DNS 异常、系统时间错误 | 换网络；校准系统时间；换 DNS 后重试 |
| 安装中断、提示未安装 | 安装包不完整、磁盘空间不足、旧版残留 | 重新从官网下载；清理空间；卸载旧版再装 |
| 更新后打不开 | 新旧版本冲突、系统版本不满足 | 卸载后装最新版；核对系统最低要求 |
| macOS 提示无法验证开发者 | Gatekeeper 拦截 | 隐私与安全性里放行，不要关闭 Gatekeeper |

排查顺序建议固定为：**完全退出 → 重启 → 查杀毒软件拦截 → 换网络 → 重新下载安装包 → 卸载重装 → 换设备验证。** 多数问题在「换网络」或「重下安装包」就能解决。换设备也打不开，更可能是账户、网络环境或平台侧问题，去官方帮助中心提工单。

## 七、装完先做这五项设置

客户端装好不等于可以开始交易。下面五项建议在充钱之前完成：

| 设置项 | 位置 | 为什么现在做 |
|---|---|---|
| **两步验证（验证器优先）** | 账户 → 安全 | 短信验证有补卡风险，验证器更稳；恢复密钥抄在纸上 |
| **防钓鱼码** | 账户 → 安全 | 官方邮件会带上你设的码，没有这个码的邮件一律当假邮件 |
| **登录设备管理** | 账户 → 安全 → 设备管理 | 定期清掉不认识的设备，发现异常登录能及时处理 |
| **提币地址白名单** | 账户 → 安全 → 提币白名单 | 即使密码泄露，攻击者也提不到新地址 |
| **API 权限清理** | 账户 → API 管理 | 不用的密钥删掉；保留的只给必要权限，关闭提币权限 |

另外两项属于使用习惯：**公共电脑上不要勾选「记住密码」；离开座位先锁定客户端。** 这两条不花钱，但能挡掉大部分「身边人顺手操作」的场景。

### 客户端相关的三类风险，怎么降低

| 风险 | 常见发生方式 | 降低办法 |
|---|---|---|
| **下载到改版包** | 山寨站、网盘、群里转发的「加速版」「绿色版」 | 只从 binance.com 域下载；装前验签名；签名不对直接删 |
| **公共电脑留下登录态** | 在共用电脑勾了记住密码、走时没退出 | 用完退出登录；清掉本地缓存；不在公共电脑做大额提币 |
| **假客服、假公告** | 页面弹窗或私信说账户异常，要求远程协助 | 官方不会索要验证码、密码、助记词，也不会要求共享屏幕；有事只在 App 或官网工单里处理 |

这三类风险分别靠验签、使用习惯和不轻信主动联系你的客服来降低。技术防护能做的有限，真正决定损失大小的是关键时刻有没有停下来核对。

## 八、算一笔账：客户端值不值得装

把成本拆开看，结论会更清楚：

| 成本项 | 网页版 | 桌面客户端 |
|---|---|---|
| 安装时间 | 0 | 5–10 分钟 |
| 每次更新 | 0 | 1–2 分钟，启动时检查 |
| 磁盘占用 | 0 | 百兆级安装包，装完更大 |
| 内存占用 | 随标签页 | 独立进程常驻 |
| 公共电脑风险 | 低 | 中，需手动清理登录态 |
| 多屏、通知、托盘 | 弱 | 强 |

**手续费和用哪个形态完全无关。** 费率只跟 VIP 等级、BNB 抵扣和邀请返佣有关，客户端不会给你更低的费率。把「装客户端」当成省钱手段，是方向错了。

值得装的只有一种人：每天看盘超过一小时、同时盯多个交易对、需要桌面通知提醒成交。其他人用网页版，把时间花在 2FA 和提币地址核对上更划算。

## 九、六个常见误区

1. **「客户端比网页版安全」** → 共用同一账户和同一套安全设置，安全取决于 2FA、防钓鱼码和设备管理，不取决于形态。
2. **「Mac 没有官方客户端，只能去第三方下」** → 官方页面是否提供 Mac 入口，以你打开时的页面为准；没有就先用网页版，不去第三方补包。
3. **「装不上就关杀毒、关 Gatekeeper」** → 先验来源和签名；两者都对，再走系统提供的「仍要运行」或「仍要打开」，不要整体关闭防护。
4. **「安装包越大越真」** → 大小可以伪造，签名和下载域名才是判断依据。
5. **「客户端下单更快，滑点更小」** → 撮合在服务器完成，客户端只是独立窗口；滑点取决于订单类型和市场深度。
6. **「旧版本更稳定，不用更新」** → 旧版本可能缺少安全修复，也可能与新版服务端不兼容；启动时提示更新就更新。

## 常见问题

**Q：币安到底有没有电脑版？**

有网页版，也有桌面客户端。平台入口会随地区和页面版本变化，以 binance.com 下载页实际显示为准；没有显示的平台先用网页版，不要从第三方站补下载。

**Q：电脑版和网页版有什么区别？**

账户、资产、撮合完全共用。区别在形态：客户端适合长时间盯盘，网页版免安装、自动最新，适合低频使用和公共电脑。

**Q：Windows 提示「未知发布者」，还能继续吗？**

先看数字签名。签名能追溯到 Binance 相关主体，且安装包来自 binance.com 域，才可以点「更多信息 → 仍要运行」。签名缺失或主体不对，直接删掉。

**Q：Mac 提示「已损坏，无法打开」怎么办？**

先删掉重新从官网下载，多数是下载不完整。仍然不行，再清除该应用的隔离属性后重试。不要为了打开一个安装包去关闭 Gatekeeper 或系统完整性保护。

**Q：电脑和手机能同时登录吗？**

可以，同一账户允许多设备登录。建议在设备管理里定期检查；公共电脑用完要退出并清理本地数据。

**Q：客户端里的功能为什么比网页版少？**

部分活动页、C2C、Launchpad 等功能没做进客户端，需要回网页版或手机 App；不是账户权限问题。
