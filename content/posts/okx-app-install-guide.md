## 二、苹果 iOS 下载：换区海外 Apple ID

由于大陆区 App Store 没有正版 OKX，iPhone 用户需要换一个海外 Apple ID 才能下载。

### 方法 A：切换海外 Apple ID（推荐）

**1. 退出当前大陆 Apple ID**

打开 App Store → 点右上角头像 → 滑到底部点「退出登录」。

**2. 登录海外 Apple ID**

有两种拿法：

- **自己免费注册**（最安全）：到苹果官网或直接在 App Store 里创建新账号，国家/地区选**香港或美国**。香港区的好处是**支持 +86 大陆手机号接收验证码**，付款方式可用支付宝香港（AlipayHK）或微信支付香港验证，对大陆用户最友好。
- **购买现成 ID**（省事但有红线）：某宝搜「港区/台湾 Apple ID」几块钱能买到，但**只在 App Store 登录、绝不登录 iCloud**——用买来的 ID 登 iCloud，对方能远程锁机敲诈。登 App Store 时若弹出「是否合并数据」，选「不合并」。

**3. 搜索并下载 OKX**

登录海外 ID 后搜「OKX」，认准开发者 **OKX Inc.**（部分版本显示为 OKX PTE. LTD.，均为 OKX 官方主体），图标是蓝底白字 OKX。除此之外的「OKX Pro」「0KX」等拼写碰瓷的，都是山寨。

**4. 下载完切回大陆 ID**

下载完成后，App Store 可以切回你日常的大陆 ID，平时使用不受影响。**但注意：以后 App 更新时，需要再次短暂登录海外 ID 才能更新**——这是换区下载的固有代价，不是「下载完就一劳永逸」。
